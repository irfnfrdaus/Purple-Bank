MEASURED INTERACTION / REFERENCE MODEL

Same PIN.
Different rhythm.

Compare press duration and pauses between digits. Both people use the same PIN and model; results come from measured key timings.

  1. First person: enter six digits at a normal, steady pace.
  2. Second person: enter the same PIN, pausing about one second between digits.
  3. Compare the measurements and scores. You can use the same phone or different phones.
No personal enrolment is used.

The reference data is generated with a median press duration of 110 ms and pause of 200 ms. The model compares timing with that reference. A slow owner may be flagged; someone else with a similar rhythm may pass.

This exercise uses two timing features only. It does not add screen pressure, accelerometer or gyroscope readings. It does not open a bank session, lock an account or transfer funds.
